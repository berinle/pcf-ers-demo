In this page we can exercise how applications in TPCF can use services. By default the applications uses H2 as an embedded database but it auto detects and uses any TPCF database bound to it.

The diagram below illustrates the TPCF components. We have Ops Manager controlling the provisioning of services where TPCF ERS is the core platform runtime services.

Pivotal Ops manager can also provision and manage other services. The Service Broker components implements an TPCF ERS API that allows services to expose their catalog in the TPCF Marketplace where they can create service instances.

We understand that not all the platform services are managed by it. So you can implement your own Service Broker and registere with TPCF ERS or you can simply use the concpet of User Provided Services.  Learn more Services.
